Pick a classifier by cross-validation, then report a score the selection never saw

Give the pipeline a CSV and a target column. It imputes, encodes and scales inside each fold, tunes five model families by grid search, picks one by cross-validated F1 on the training split, and only then scores everything on a held-out test set. Results below are from five datasets.

01Why selection must not use the test set

An earlier version of this project ranked the models by test-set F1 and reported the winner's test score. That score is biased upward: taking the best of five noisy estimates picks the model that got lucky on those particular test rows (Cawley & Talbot, 2010). The fix is to choose with cross-validation on the training split, so the test set is used exactly once.

02Other fixes in this version

  1. Multiclass targets crashed. Scoring was hard-coded to binary F1 and the logistic-regression grid included the binary-only liblinear solver, so any three-class CSV failed. Labels are now integer-encoded, binary problems use F1 and multiclass use macro F1.
  2. String labels and missing targets. Targets like "yes"/"no" now work, and rows with a missing target are dropped instead of breaking the split.
  3. Deprecated API. SVC(probability=True) is deprecated in scikit-learn 1.9 and will be removed in 1.11. It is replaced with CalibratedClassifierCV(SVC(), ensemble=False).
  4. A redundant, biased CV pass that re-scored the tuned model on the same folds was removed; the grid search's own CV score and spread are reported instead.

03Run it

pip install -r requirements.txt
python src/main.py --data data/breast_cancer.csv --target target
python scripts/run_benchmarks.py   # regenerates docs/results.json
pytest -q tests

Outputs: results/results.csv (ranked by CV F1, with a selected column), results/model_comparison.png and models/best_model.pkl.

Cawley, G. C. & Talbot, N. L. C. (2010). On over-fitting in model selection and subsequent selection bias in performance evaluation. JMLR 11, 2079–2107. The first four datasets ship with scikit-learn; the fifth is synthetic, generated by scripts/run_benchmarks.py.
